# 💑 우리 부부 공유 캘린더 (구글 스프레드시트 실시간 연동)

컴퓨터, 남편 휴대폰, 아내 휴대폰 어디서나 일정을 등록/수정/삭제하면 **구글 스프레드시트와 실시간으로 자동 동기화**되는 한국 공휴일 적용 부부 캘린더입니다.

---

## 🌟 주요 특징

1. **📊 구글 스프레드시트 실시간 양방향 연동**
   - 컴퓨터, 아내 폰, 남편 폰에서 수정한 일정이 구글 시트에 즉시 반영되고 동기화됩니다.
   - 엑셀 형태로 언제든지 일정을 백업 및 확인할 수 있습니다.
   - 앱을 켜거나 브라우저 창으로 돌아올 때 자동으로 최신 일정을 불러옵니다.

2. **📅 한국 공휴일 완벽 적용 달력**
   - 신정, 설날/추석 연휴, 삼일절, 선거일, 어린이날, 부처님오신날, 현충일, 광복절, 개천절, 한글날, 성탄절 및 **대체공휴일** 자동 표시
   - 공휴일/일요일 빨간색, 토요일 파란색 및 공휴일 배지 지원

3. **⏰ 날짜 & 시간별 일정 등록**
   - **담당자 구분**: 👩 아내(나) / 👨 남편 / 💑 우리 함께
   - **시간 설정**: '종일 일정' 또는 '시작 시간 ~ 종료 시간(HH:mm)'
   - **카테고리 & 메모**: 데이트, 집안일, 장보기, 운동, 기념일, 병원 등

---

## 🚀 구글 스프레드시트 1분 연동 방법

1. **[구글 스프레드시트](https://sheets.google.com)**에서 새 시트를 하나 만듭니다. (예: `부부 캘린더`)
2. 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
3. 기존 코드를 지우고, 이 폴더의 **[`google_sheet_code.js`](./google_sheet_code.js)** 파일 내용(또는 앱 내 설정의 '연동 코드 복사')을 그대로 붙여넣고 **저장(💾)**합니다.
4. 오른쪽 상단의 파란색 **[배포] → [새 배포]**를 누릅니다:
   - 유형: **웹 앱 (Web app)** 선택
   - 액세스 권한: **모든 사용자 (Anyone)** 선택 ⭐
5. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. **[`index.html`](./index.html)**을 브라우저에서 열고 우측 상단 **[⚙️ 구글 시트 설정]**에 URL을 붙여넣고 저장하면 연동 완료!

## 📱 남편 스마트폰 / 내 스마트폰에서 사용하는 방법

1. `index.html` 파일을 클라우드(GitHub Pages, Vercel, Netlify 등 무료 호스팅)에 올리거나 링크를 공유합니다.
2. 스마트폰 브라우저(Safari 또는 Chrome)로 링크를 연 후, 브라우저 메뉴의 **[홈 화면에 추가]**를 누르면 스마트폰 앱처럼 설치되어 사용할 수 있습니다!
