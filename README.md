# 💑 우리 부부 스케줄 공유 달력

한국 공휴일(명절 연휴 및 대체공휴일 포함)이 완벽하게 적용된 **남편 & 아내 전용 스케줄 공유 달력**입니다.  
불필요한 기능 없이, 컴퓨터와 스마트폰 어디서나 한눈에 들어오는 **한 화면(One-Screen)** 대시보드로 부부의 일정을 손쉽게 등록하고 실시간으로 공유할 수 있습니다.

---

## 🌟 핵심 특징

1. **👀 한 화면(One-Screen) 뷰 (모바일 & PC 완벽 지원)**
   - 스크롤을 헤맬 필요 없이 브라우저 한 화면에 꽉 찬 레이아웃
   - **PC/태블릿**: 좌측 대형 월간 캘린더 + 우측 남편/아내 일정 타임라인 & 빠른 추가
   - **스마트폰**: 상단 콤팩트 월간 달력 + 하단 오늘/선택일 일정 상세

2. **🇰🇷 2024~2035년 한국 공휴일 & 대체공휴일 완벽 적용**
   - 신정, 설날/추석 연휴, 삼일절, 총선/선거일, 어린이날, 부처님오신날, 현충일, 광복절, 개천절, 한글날, 성탄절 및 모든 **대체공휴일** 자동 계산 및 빨간날 표시
   - 토요일(파란색), 일요일/공휴일(빨간색) 명확한 시인성

3. **👥 남편 / 아내 스케줄 명확한 색상 분리**
   - 👨 **남편 스케줄**: 시원한 블루 컬러 칩
   - 👩 **아내 스케줄**: 화사한 핑크 컬러 칩
   - 💜 **함께하는 스케줄**: 우아한 퍼플 컬러 칩
   - 달력만 쓱 봐도 이번 달에 누가 언제 일정이 있는지 1초 만에 파악 가능

4. **⚡ 군더더기 없는 초간단 일정 입력**
   - 담당자([남편] / [아내] / [함께]) 선택 -> 제목 -> 시간 -> 간단 메모만 입력하면 등록 끝!
   - 복잡한 카테고리나 불필요한 기능 배제로 빠르고 직관적인 사용성

5. **📊 구글 스프레드시트 실시간 무료 양방향 연동**
   - 남편 스마트폰, 아내 스마트폰, 회사/집 컴퓨터 어디서 등록하든 구글 시트를 통해 실시간 자동 공유

## 🚀 스마트폰 & PC 실시간 부부 공유 설정 (1분 소요)

1. **[구글 스프레드시트(Google Sheets)](https://sheets.google.com)**에서 새 스프레드시트를 하나 만듭니다. (예: `우리 부부 달력`)
2. 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
3. 기존 코드를 모두 지우고, 이 폴더의 **[`google_sheet_code.js`](./google_sheet_code.js)** 파일 내용을 그대로 붙여넣은 후 저장(💾)합니다.
4. 오른쪽 상단의 파란색 **[배포] → [새 배포]**를 클릭합니다:
   - 유형: **웹 앱 (Web app)** 선택
   - 설명: `부부 달력 연동`
   - 다음 사용자로 실행: `나`
   - 액세스 권한: **모든 사용자 (Anyone)** 선택 ⭐ (필수)
5. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 달력 화면 우측 상단의 **[⚙️] 설정 아이콘**을 누르고 URL을 붙여넣은 뒤 [저장 및 동기화]를 누르면 완료!

## 📱 스마트폰에서 앱처럼 사용하는 법

1. 달력 상단의 **[📱 폰 연결]** 버튼을 누르면 QR코드가 표시됩니다.
2. 배우자의 스마트폰 카메라로 QR코드를 비추어 링크를 엽니다.
3. 스마트폰 브라우저(Safari 또는 Chrome) 메뉴에서 **[홈 화면에 추가]**를 누르면 스마트폰 전용 앱처럼 홈 화면에서 바로 열립니다!
